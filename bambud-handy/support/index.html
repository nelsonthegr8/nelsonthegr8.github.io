Frequently asked questions

What do I need?

A running Bambuddy server that your printers are added to, and an API key from it (Bambuddy → Settings → API Keys). Turn on Control printer for the key if you want to pause, stop or start prints from the app. Want to look around first? Tap Try demo mode on the connect screen.

Can I use it away from home?

Yes, if your phone can reach your Bambuddy server: over a VPN (such as Tailscale or WireGuard) or an HTTPS address you've set up for it.

Printing from MakerWorld says it needs a Bambu sign-in

Bambuddy downloads MakerWorld models with your Bambu Lab account. Sign in under Me → Bambu Cloud and allow it to be shared with Bambuddy, or sign in to Bambu Cloud in Bambuddy itself.

The printer says it "could not parse the file"

MakerWorld projects have to be sliced before printing. BamBud Handy slices them on your Bambuddy server first, which needs a slicer set up in Bambuddy. If slicing isn't available, slice the model in Bambu Studio and upload it to Bambuddy's library instead.

How do I get alerts when the app is closed?

iPhone only lets apps check in now and then while closed. For instant alerts, have Bambuddy send them through the free ntfy app: Me → Print alerts → Instant alerts walks you through it. Tapping an ntfy alert opens ntfy; open BamBud Handy yourself to see the printer.

Is this made by Bambu Lab?

No. BamBud Handy is an independent app, not made by or affiliated with Bambu Lab or the Bambuddy project.
